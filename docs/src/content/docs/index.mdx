<p class="kh-section-lead">The two failure modes</p>

<CardGrid>
  <Card title="The machine lies" icon="warning">
    Stale or wrong, asserted with confidence. **Archon** + **Nexus** defend by grounding answers in verifiable sources — never asserting soft answers.
  </Card>
  <Card title="The human stops judging" icon="approve-check">
    AI output rubber-stamped without reading. **specledger** defends by making accountable review a gate before code is written.
  </Card>
</CardGrid>

<p class="kh-section-lead">The three debts of the AI era</p>

<CardGrid>
  <Card title="Technical debt">
    Artifacts pile up faster than they're maintained. **mutqa** + **Probe** service it.
  </Card>
  <Card title="Intent debt">
    Why a thing was built — its constraints and trade-offs — is lost. **specledger** services it.
  </Card>
  <Card title="Cognitive debt">
    Nobody understands the system the org ships. The open leg Khala is built to close — *AI builds it, you understand it.*
  </Card>
</CardGrid>
