<p class="kh-section-lead">Two ways AI work goes wrong</p>

<div class="kh-grid-2">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>Confident wrong answers</h3>
    <p>Models state stale or incorrect facts with full confidence. <strong>Nexus</strong> and <strong>Archon</strong> answer only from sources they can cite, so every claim comes with its evidence.</p>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>Unreviewed AI output</h3>
    <p>AI-written code gets approved without a real read. <strong>Arbiter</strong> makes review an explicit, recorded gate before code is written.</p>
  </div>
</div>

<p class="kh-section-lead">One substrate, four kinds of information</p>

<div class="kh-grid-2">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>What the org knows</h3>
    <p>One warehouse, two doors — humans (web) and agents (MCP) read the same governed corpus: same approvals, same current version, same citations.</p>
    <span class="kh-tag">Nexus</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>Why it was built</h3>
    <p>A flight recorder for design decisions — the choices agents make by the hundred, recorded at zero cost and approved as a named human's accountable act.</p>
    <span class="kh-tag">Arbiter</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">03</span>
    <h3>What the system is doing</h3>
    <p>Judgment context, not another dashboard — telemetry joined with approved knowledge into evidence for review and troubleshooting.</p>
    <span class="kh-tag">Observer · Nexus</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">04</span>
    <h3>Who still understands it</h3>
    <p>A cognitive-debt ledger — the warehouse is the denominator, vouches the numerator; the gap becomes a number the team can repay.</p>
    <span class="kh-tag">Adept</span>
  </div>
</div>

<p class="kh-section-lead">Three debts it pays down</p>

<div class="kh-debts">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>Technical debt</h3>
    <p>Code and artifacts pile up faster than anyone maintains them.</p>
    <span class="kh-tag">Serviced by Probe · Observer</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>Intent debt</h3>
    <p>The reasons behind a decision, and its trade-offs, get lost.</p>
    <span class="kh-tag">Serviced by Arbiter</span>
  </div>
  <div class="kh-cell kh-cell--wide">
    <span class="kh-num">03</span>
    <h3>Cognitive debt</h3>
    <p>No one fully understands the system the team ships. Closing that gap is the point of Khala: <strong>you can still read and trust what the AI built.</strong> Adept turns the gap into a number — vouch coverage — so repayment can be planned.</p>
    <span class="kh-tag">Measured and repaid via Adept</span>
  </div>
</div>
