생산자 도구들은 서로를 직접 호출하지 않습니다. **오직 Khala를 통해서만** 연결됩니다 — 점대점 배선의 거미줄이 아니라, 하나의 연결.

- **Archon**은 단 하나의 권위 창구입니다: 사람과 에이전트가 도메인 진실을 물으러 옵니다.
- **Observer**는 개발자와 나란히, 그 창구의 한 소비자입니다.
- **Arbiter**는 승인된 명세를 Khala에 게시합니다 — 하지만 진실의 원천은 아닙니다; 권위 있는 frontmatter가 원천입니다.
