<p class="kh-section-lead">AI 기반 개발에서 발생하는 핵심 위험</p>

<div class="kh-grid-2">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>확신에 찬 오답</h3>
    <p>모델은 만료되거나 부정확한 사실도 확신을 갖고 생성합니다. <strong>Nexus</strong>와 <strong>Archon</strong>은 인용 가능한 공식 출처에만 한정하여 응답하므로, 모든 주장에 검증 가능한 근거가 결속됩니다.</p>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>형식적 검토 및 무비판적 수용</h3>
    <p>AI 생성 코드가 엔지니어링 검토 없이 승인되는 위험을 차단합니다. <strong>Arbiter</strong>는 코드 구현 착수 이전에 설계 및 인터페이스 리뷰를 명시적이고 영속적인 거버넌스 게이트로 강제합니다.</p>
  </div>
</div>

<p class="kh-section-lead">단일 기판, 네 종류의 정보 흐름</p>

<div class="kh-grid-2">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>조직의 공인 지식</h3>
    <p>단일 지식 기판, 이중 접근 인터페이스 — 사람(Web UI)과 에이전트(MCP)가 동일한 통제 코퍼스를 참조합니다: 단일 진실 공급원, 최신 버전 동기화, 검증된 인용 체계.</p>
    <span class="kh-tag">Nexus</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>설계 의도 및 의사결정 이력</h3>
    <p>아키텍처 결정 레코더 — 에이전트가 생성하는 대규모 의사결정 트레이드오프를 결정론적으로 기록하고, 승인은 공인된 엔지니어의 명시적 책임 행위로 영속화합니다.</p>
    <span class="kh-tag">Arbiter</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">03</span>
    <h3>런타임 시스템 관측 상태</h3>
    <p>단순 모니터링을 넘어선 판단 맥락 제공 — 실시간 텔레메트리를 승인된 지식과 결합하여 리뷰 및 장애 분석의 신뢰할 수 있는 증거를 구성합니다.</p>
    <span class="kh-tag">Observer · Nexus</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">04</span>
    <h3>인지 이해도 및 보증 현황</h3>
    <p>인지 부채 원장 — 전체 배포 아티팩트가 분모, 유효한 인간 보증(Vouch)이 분자; 미검증 자산의 간극을 정량화하여 측정 가능한 지표로 통제합니다.</p>
    <span class="kh-tag">Adept</span>
  </div>
</div>

<p class="kh-section-lead">Khala가 통제하는 3대 엔지니어링 부채</p>

<div class="kh-debts">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>기술 부채 (Technical Debt)</h3>
    <p>코드와 배포 산출물이 유지보수 수용 속도보다 빠르게 누적되는 현상.</p>
    <span class="kh-tag">Probe · Observer로 완화</span>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>의도 부채 (Intent Debt)</h3>
    <p>설계 결정의 배경, 대안 평가 및 엔지니어링 트레이드오프가 망실되는 현상.</p>
    <span class="kh-tag">Arbiter로 추적 관리</span>
  </div>
  <div class="kh-cell kh-cell--wide">
    <span class="kh-num">03</span>
    <h3>인지 부채 (Cognitive Debt)</h3>
    <p>팀이 배포하는 시스템의 내부 동작을 엔지니어가 완전히 이해하지 못하는 불일치 현상입니다. Khala는 이 간극을 제거합니다: <strong>AI가 생성한 산출물을 엔지니어가 명확히 검증하고 신뢰할 수 있도록 보장합니다.</strong> Adept는 이를 보증 커버리지(Vouch Coverage) 메트릭으로 정량화하여 체계적인 해소를 지원합니다.</p>
    <span class="kh-tag">Adept로 정량화 및 통제</span>
  </div>
</div>
