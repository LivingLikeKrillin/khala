<p class="kh-section-lead">두 실패 모드</p>

<div class="kh-grid-2">
  <div class="kh-cell">
    <span class="kh-num">01</span>
    <h3>기계가 거짓말한다</h3>
    <p>낡거나 틀린 답을 확신에 차서 단언한다. <strong>Archon</strong> + <strong>Nexus</strong>는 검증 가능한 출처에 답을 묶어 방어한다 — 근거 없는 답은 결코 단언하지 않는다.</p>
  </div>
  <div class="kh-cell">
    <span class="kh-num">02</span>
    <h3>사람이 판단을 멈춘다</h3>
    <p>AI 출력을 읽지도 않고 고무도장처럼 승인한다. <strong>Arbiter</strong>는 코드가 작성되기 전, 책임 있는 리뷰를 게이트로 만들어 방어한다.</p>
  </div>
</div>
