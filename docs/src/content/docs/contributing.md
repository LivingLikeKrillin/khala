title: Contributing
description: For future collaborators and open-source contributors.
---

These docs and the tools they describe are built in the open for future collaborators. For now, contribution happens in each tool's own repository — [Nexus/Archon](https://github.com/LivingLikeKrillin/khala), [Probe](https://github.com/LivingLikeKrillin/probe), and [specledger](https://github.com/LivingLikeKrillin/specledger) — where you can open issues and pull requests.

A formal contribution flow, coding conventions, and review guidelines for this docs site will expand here as the ecosystem matures. If you want to help in the meantime, start a discussion in the relevant repo.
