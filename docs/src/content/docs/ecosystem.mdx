---
title: Ecosystem Topology
description: Inter-tool interface and architectural topology over the Khala substrate.
---

Producer tools across the Khala ecosystem avoid direct coupling, exchanging all state and specifications via the **Khala common substrate and protocol contracts**. This eliminates point-to-point mesh dependencies in favor of a centralized hub topology.

<img
  src="/diagrams/ecosystem.svg"

/>

- **Archon**: Provides a single authority window directly mapped to static codebase constants and domain invariants.
- **Observer**: Consumes the Khala substrate alongside human reviewers to verify PR architectural integrity and runtime telemetry impacts.
- **Arbiter**: Publishes verified, approved architectural specifications (SPECs) into the substrate; validity is guaranteed by immutable frontmatter content hashes.
- **Adept**: Audits the substrate as an evaluation ledger, measuring vouch coverage of human comprehension against the full knowledge corpus denominator.
