- issue_id: I-002
  category: missing-invariant
  severity: high
  description: §5 requires "the same image bytes must yield the same stored text"
    and names a cache as the mechanism, but states no invariant on cache durability,
    loss, or eviction. A cache miss (rebuild, retention policy, new environment, cache-store
    migration) re-runs a non-deterministic extractor and produces drifted text under
    an unchanged extractor identity and prompt version — exactly the churn §5 exists
    to prevent, silently poisoning ADR-0006's `content_hash` idempotency and entropy
    signal ②. The invariant that actually holds the spine is "stored text for unchanged
    bytes never changes" (i.e., stored text is authoritative on cache miss, or the
    cache is durable and backed up), and it is not stated.
