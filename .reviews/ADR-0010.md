- issue_id: I-001
  category: adr-contradiction
  severity: high
  description: §6 asserts "Its output is data, never instruction... nothing downstream
    interprets it as direction", but §4 hop 3 requires the extracted text to reach
    "the evidence packet, and therefore the LLM prompt". Attacker-authored text placed
    in an image is therefore delivered verbatim into an LLM context — the textbook
    indirect prompt-injection path. The only control named is the quarantine scanner,
    which (per ADR-0006/ADR-0002) is a default-deny content gate, not an injection

    one of the three is unenforceable given §4.
  status: accepted
  disposition_reason: 'Fixed. ''Its output is data, never instruction'' was false
    — hop 3 sends extracted text to the LLM prompt, which is the point of extracting
    it. Narrowed to what is true: no code branches on it; prompt injection through
    retrieved evidence is a property Nexus already has via every ingested document;
    what extraction changes is the channel (text a human reviewing the document would
    not see), which is what the tier labels.'
