# Adept 문항 설계 메모

질문 생성 세션이 `save-questions` 전에 지킬 것. (2026-07-02 첫 상환 루프에서 나온 교훈)

- **상황에서 출발, 산출물은 정답지.** 문항에 문서명/ID를 노출하지 않는다
  ("~에 따르면" 금지). 실무 지식은 문서 단위로 인출되지 않는다.
- **회상 금지.** 편집 이력·인용 출처·문구 암기는 이해가 아니다.
- **한 문항 = 한 판단.** 통과 기준은 문구 재현이 아니라 결정+이유의 요지.
- 좋은 형태: 판정("이 제안, 수용?"), 반박("이 반문에 뭐라 답할?"),
  선행조건("시작하려면 뭐가 먼저?"), 경계("이 요구 수용해야?"), 운영("이 증상, 어디부터 의심?").
- "모르겠다"는 유효한 답 → `--failed` 기록 → 보완 학습 → 재시도. 첫 실패는 정상 경로.
